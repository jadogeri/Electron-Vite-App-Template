## Behavior and wiring

Main factory reads the OS locale after host readiness, normalizes BCP-47 and underscore tags, and persists `localePreference` (`system`, `en`, `es`) in the existing `preferences` electron-store without replacing the theme/settings object. Unsupported or corrupt values fall back safely. Resources are bundled; there is no translation fetch.

The global renderer plugin uses real i18next/react-i18next, renders an accessible language selector, updates document language, and publishes the translator through the core adapter. Main publishes the translator through `setMainTranslator`, refreshes menus, and emits `changed`. Renderer subscribes before the snapshot and removes its listener on unmount. Native platform-role menu labels must be passed through `translateMain`, not assumed to follow application locale automatically.

Production dependencies: `i18next ^27.1.5`, `react-i18next ^18.0.2`. Both bundles can import pure `main/features/i18n/resources.ts`; that file imports no Electron, Node or main plugin code. Core must use `useTranslate()` for all strings and the literal keys in resources. Formatting helpers export locale-aware `formatNumber` and `formatDate`. User-provided filenames/error details are values, never keys.

Methods: `getState()` and `setPreference(preference)`; event `changed` with `{preference, locale}`.

The i18next raw API escapes interpolation. `textTranslator` disables duplicate escaping only for React/native text labels; **never use it with innerHTML or HTML injection**. Versions and progress should be passed as text/locale-formatted numbers. Complete parallel English/Spanish keys cover the existing navigation, home, dashboard, settings, loading, fallback, updater and menu surfaces.

## RTL strategy

Both bundled languages are LTR, so the plugin explicitly sets `dir=ltr`. Adding RTL requires a new allowlisted locale, complete translations, direction from `i18next.dir`, logical CSS properties, and keyboard/native-menu inspection. RTL support is not claimed by the two-locale implementation.
